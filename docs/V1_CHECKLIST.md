# v1.0 checklist (SPEC §45)

This file traces each v1.0 completion condition in [SPEC.md §45](../SPEC.md) to the code that implements it, the
tests that cover it, and what is still open. It was written on 2026-09-24 from a read-only audit of `main`, after
all modules and the audit-fix round were merged. At that point the 635 unit tests in `FANBOXClientTests` passed, and
the UI tests in `FANBOXClientUITests` ran a screen tour with the demo accounts (the screens the tour does not open are
listed under [Smaller points](#smaller-points-noted-during-the-audit)).

Links point into the repository and show the file name and the line that was read during the audit. Line numbers
drift as the code changes, so treat them as a starting point. A bare `:N` in a cell refers to the file named just
before it.

to end and covered by tests. Native media upload for real FANBOX accounts uses `post.addImage` / `post.addFile` /

client.

## Live-service verification

The app has been verified on a real iPhone with real FANBOX accounts. The automated tests still never reach FANBOX:
the UI tests run on the demo accounts (`DemoRemoteDataSource`), which bypass the HTTP stack, and the unit tests drive
the request pipeline with `URLProtocol` stubs and fake data sources. Endpoint paths and response shapes were collected
from public sources ([API.md](API.md) §0), each with a confidence rating for its sources.

### When FANBOX changes

The FANBOX API is unofficial and can change. Research Mode (Settings → Research) shows what changed. Turn it on before
logging in, so response bodies are kept (redacted). With demo accounts the Requests, Responses and API Schema lists
stay empty.

- **Live API チェック** calls every read endpoint the app uses once with one of your accounts and reports per endpoint
  whether the call worked and which fields were new or missing. Its masked report goes into
  `FANBOXClientTests/Research/LiveReports/`, where `LiveContractTests` decodes it with the app's decoders.
- **API Schema** and **Sync / Errors** show new and missing fields and decode failures from normal use.
- **Requests, Responses and Navigation** show redacted traffic. The 通信経路 (transport) switch forces Native のみ or
  WebView のみ when Cloudflare starts blocking one transport.
- For Creator Mode writes, use a throwaway draft. Adding an image in the web editor with Research Mode on shows the web
  client's own request next to the app's.
- Record what changed in docs/API.md with the date.
